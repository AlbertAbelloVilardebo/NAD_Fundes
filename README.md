# NAD

Aplicació Android que mostra el visor web de NAD dins d'un `WebView`.

URL inicial: `http://217.154.181.249/ws/pautestallers/visor2.php`

La primera cadena de redireccions del servidor es permet perquè el visor pugui carregar. Quan arriba a la pàgina final, la navegació principal queda bloquejada en aquell mateix document. Els recursos interns i els marcs de la pàgina poden carregar amb normalitat.
